# Figure Accessibility Notes

Primary figure: heatmap of DepMap 24Q4 TPM values for 17 connexin genes in 8 lung cancer cell lines. Rows are cell lines and columns are genes. Darker red indicates higher TPM. The strongest signal is GJA1 in A549 and Calu-1, with Calu-1/GJA1 defining the TPM-native maximum (91.71 TPM). GJD3 values are low but detectable in all selected lines except values near zero are not omitted.

Underlying numeric values are available in `tables/depmap_24q4_tpm_matrix.tsv`.
